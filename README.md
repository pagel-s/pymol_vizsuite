# PyMOL Viz Suite

**Molecular figures with an editorial eye.**

PyMOL Viz Suite turns a loaded structure into a polished scientific plate, a
cinematic talk image, or an annotated close-up with one memorable command. It
is a single Python file, has no dependencies beyond a standard PyMOL install,
and never hides the work: `viz_script` exports the plain PyMOL commands behind
the current look.

## The whole workflow

```pml
fetch 4hhb, async=0
viz paper
viz_render ~/haemoglobin.png, fit, width=2400
```

That is a publication-ready starting point: clean cartoon geometry, restrained
colour, measured framing, and a final render at the shape your molecule needs.
Use `viz_auto` when the structure should choose for itself.

| Your intent | Command | Result |
|---|---|---|
| A paper figure | `viz paper` | Clean journal cartoon |
| A talk or cover image | `viz story` | Cinematic light, depth, and atmosphere |
| A molecular illustration | `viz illustration` | Inked, Goodsell-inspired space filling |
| A ligand-binding close-up | `viz site` | Framed pocket, contact residues, ligand detail |
| An AlphaFold model | `viz confidence` | Official pLDDT confidence colours |

These are friendly aliases for the complete styles (`publication`, `cinematic`,
`illustrative`, `pocket`, and `plddt`). They are designed to be the only names
you need to remember. Run `viz_list` when you want the full palette.

## Install

Clone the repository, then either load it once:

```pml
run /path/to/pymol_vizsuite.py
```

or load it whenever PyMOL starts:

```bash
git clone https://github.com/pagel-s/pymol_vizsuite.git ~/pymol-vizsuite
echo 'run ~/pymol-vizsuite/pymol_vizsuite.py' >> ~/.pymolrc
```

You can also use **Plugin Manager → Install New Plugin → Choose file…**. The
suite supports open-source PyMOL 2.x and 3.x. PyMOL's bundled `numpy` and Qt
enable the finished outline, labels, keys, and figure-composition passes; the
styles still render without them.

## Make the result yours

Start with intent, then add only the decision that matters:

```pml
# Make a paper figure communicate secondary structure.
viz paper, coloring=ss

# Make a story image from a large assembly.
viz story, frame=slide, view=hero
viz_render ~/assembly-slide.png, slide

# Bring one loop forward without rebuilding the look.
viz paper
viz_focus resi 140-170, 0.8

# Compare the suitable looks visually instead of guessing style names.
viz_gallery
```

`viz_render` is the finishing step. It ray-traces, holds ink weight constant
at any output size, and adds the scale bar or colour key when the selected
style needs one.

`viz story` intentionally leaves those annotations off: a cover or customer
pitch should be all molecule. Add them explicitly when that same cinematic
lighting serves a labelled figure: `viz_render figure.png, legend=1,
scalebar=20, name=Complex`.

```pml
viz_render ~/figure.png, column, scalebar=20     # 88 mm at 300 dpi
viz_render ~/figure.png, dcolumn                 # double journal column
viz_render ~/figure.png, fit, width=2400         # match the molecule's shape
viz_render ~/slide.png, slide                    # 16:9 presentation image
```

## A little more power, only when you need it

The suite keeps expert work close to the basic loop:

```pml
# Binding interface at overview, footprint, and residue-detail scale.
viz interface
viz epitope
viz contacts

# Make a multi-panel figure from finished renders.
viz_figure apo.png:apo holo.png:holo, figure-1.png, cols=2, title=Figure 1

# Export the ordinary PyMOL commands that reproduce the current style.
viz_script figure-style.pml
```

There are specialised styles for nucleic acid, density-like surfaces,
hydropathy, charge, schematic review figures, and more. They remain available
for specific questions; the [reference](docs/REFERENCE.md) is the complete
contract.

## Design principles

- **Meaning before decoration.** A journal figure stays quiet until colour,
  labels, or a key are needed to explain the science.
- **Camera as composition.** New structures are oriented, projected, and
  framed from their actual visible shape instead of being left as screenshots.
- **Cinematic when appropriate.** `viz story` uses depth, rim light, and bloom
  for talks and covers—not for a quantitative panel.
- **Reproducible by default.** Every gallery image is generated by the command
  printed below it, with no manual retouching.

## Need a starting point?

```pml
viz_auto
viz_render ~/figure.png, fit, width=2400
```

Then ask PyMOL for the next useful action: `help viz`, `help viz_render`, or
`viz_list`.
